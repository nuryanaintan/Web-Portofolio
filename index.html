Halo! Saya mahasiswa Sistem Informasi semester 5 di Universitas Musamus. Saya tertarik mempelajari berbagai hal seputar teknologi, mulai dari pengembangan web, sistem informasi, sampai UI/UX Design — terutama soal bagaimana tampilan aplikasi bisa dibuat rapi dan nyaman dipakai.

Saya senang belajar hal baru secara mandiri, baik lewat kuliah, project kecil, maupun organisasi kampus. Sekarang saya sedang fokus mengembangkan kemampuan di bidang UI/UX Design dan terbuka untuk belajar bareng atau berkolaborasi di project apa pun.
